# Soos for PowerToys Run <!-- lint-ok -->

A PowerToys Run plugin that hands your query to `soos-cli --json` and shows
the answer as the Soos app would. Enter copies the plain value, without
thousands separators, as clicking a result in the app does.

[Install the PowerToys Run plugin](../../docs/powertoys.md) has the
requirements, the build and install steps, and what to do when it fails.
